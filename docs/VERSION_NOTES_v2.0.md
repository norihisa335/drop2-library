# Version Notes v2.0

- Refreshed Home navigation and added Browse by Chord.
- Added Drop3, Shell, and Triad libraries.
- Added Chord Changes (Play): up to five chords with Ascending, Descending, Nearest, and Root Position patterns.
- Added iPhone horizontal-scroll support for Play.
- Browse by Chord printing supports A4 portrait (4 columns × up to 6 rows) and landscape (6 columns × up to 4 rows).
- Improved Degree labels.
- Data master v5 contains 219 forms: Drop2 64, Drop3 64, Shell 19, Triad 72.
- Browse by Chord: Maj7 24, 7 24, m7 24, m7b5 17.
- Corrected `7-14-1-P-01` frets to `[2, 3, 3, 3]`.

Known follow-up items: m7b5 orders 18–24 are unassigned; Study remains the existing v10-equivalent implementation pending later cleanup; Play may be refined after practical use.
